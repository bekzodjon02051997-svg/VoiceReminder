# Changelog

## 1.0.0
- Uzbek voice input (system speech recognizer, `uz-UZ`) and typed input
- Offline rule-based parser: splits one utterance into several numbered reminders
- Room database, AlarmManager scheduling, boot / timezone recovery
- Two-stage completion: DONE -> CONFIRM DONE / NOT YET; swipe never completes
- Recurring reminders (daily, weekly, monthly, every N units)
- Today / Upcoming / All / Completed / Unscheduled views, search, edit, reschedule, delete
